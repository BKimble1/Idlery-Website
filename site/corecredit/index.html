In short

One narrow job, done end to end.

When a shop buys a replacement part, the supplier adds a refundable core charge for the old one. That money comes back only if the old part reaches the right vendor before the deadline, and only if the vendor actually issues the credit.

CoreCredit is the ledger for that money. Log the core, return it on time, and keep it open until the credit arrives. It is not a repair-order system or an accounting product.
